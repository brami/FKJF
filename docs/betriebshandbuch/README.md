# Betriebshandbuch

`betriebshandbuch_webseite.pdf` – für die Betreuung: Aufbau, Server einrichten, Updates,
Einstellungen, Datensicherung und Totalausfall, Störungen, Verwaltungsaufgaben, Wartungsplan.

Grundlage ist `deploy/setup-server-fv-web.sh`; bei Änderungen am Skript mitpflegen.
PDF erzeugen: `pdflatex betriebshandbuch_webseite.tex` (dreimal).
